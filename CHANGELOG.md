# Changelog

## 2026-10-15

- Создан проект Qt для демонстрации дерева объектов и автоматического удаления виджетов.
- Добавлены классы `LogLabel`, `LogButton`, `LogLineEdit` и `LogPanel` с выводом сообщений в `qDebug()`.
- Реализованы кнопки для перемещения виджета между родителями и демонстрации `setParent(nullptr)`.
- Добавлены описание проекта, инструкция по сборке и краткий отчёт по лабораторной работе.
